<a href="https://llm.nrp-nautilus.io/ui/"><Image src="~/assets/images/docs/litellm-logo.png" alt="LiteLLM Logo"/></a>
We use the [LiteLLM](https://www.litellm.ai) proxy to provide access to the LLMs we're running on nautilus.

You can start from logging to the [NRP litellm UI](https://llm.nrp-nautilus.io/ui/). If you're coming from an .edu domain, you'll be placed into NRP team unless you're in a special SDSC list, in which case you'll be placed in the SDSC team. Otherwise request in [Matrix](/documentation/userdocs/start/contact/) to be assigned to a Team. 

Once you're a member of a team, you can create the tokens and access the models.

To create a token, open the Virtual Keys tab and create a new token to access the API. There are also examples on using the API.
</p>
</Fragment>
