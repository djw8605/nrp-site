## Chat Interfaces

If you are looking to chat with an LLM model similar to the interface provided by [ChatGPT](https://chatgpt.com/), we provide 2 options:

1. [LibreChat](https://librechat.nrp-nautilus.io) - A simple chat interface for all of the NRP hosted models.  **Status:** Pre-production: We are working to improve librechat.
2. [AnythingLLM](https://nrp-llm-chat.nrp-nautilus.io) - A chat interface that allows the uploading of documents in order to chat with documents.

## API Access to LLMs

API access to the LLM is provided through an [LiteLLM](https://www.litellm.ai/) proxy.  In order to access our LLMs, you need to:

<Steps>

1. Login to [NRP's LiteLLM](https://llm.nrp-nautilus.io/ui) instance.

2. Create an API key. During key creation, you will select the models that the key is allowed to access (or all models).

3. With the API key, you are able to access the API through the endpoint `https://llm.nrp-nautilus.io/`.  An example of how to use the API is below [Python code](#example-python-code).

</Steps>

## Example Python Code

To access the NRP LLMs, you can use the [OpenAI Python client](https://github.com/openai/openai-python).  Below is an example of how to use the OpenAI Python client to access the NRP LLMs.

```python title="nrp-llm.py"
import os
from openai import OpenAI

client = OpenAI(
    # This is the default and can be omitted
    api_key = os.environ.get("OPENAI_API_KEY"),
    base_url = "https://llm.nrp-nautilus.io/"
)

completion = client.chat.completions.create(
    model="gemma3",
    messages=[
        {"role": "developer", "content": "Talk like a pirate."},
        {
            "role": "user",
            "content": "How do I check if a Python object is an instance of a class?",
        },
    ],
)

print(completion.choices[0].message.content)
```
