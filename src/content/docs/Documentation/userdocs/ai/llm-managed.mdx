The NRP hosts a rotating catalog of open-weights LLMs, accessible either through hosted **chat interfaces** in the browser or programmatically via an **OpenAI-compatible API**. Models are added and retired as the open-weights frontier moves — see the [feature matrix](/documentation/userdocs/ai/llm-managed/models) for the current lineup and the [changelog](/documentation/userdocs/ai/llm-managed/lifecycle) for what changed and when.

## How to use the LLMs

If you want to **chat in a browser**, [Open WebUI](/documentation/userdocs/ai/llm-managed/chat-interfaces#open-webui) is the most full-featured option. We also host LibreChat, and the same API works with desktop apps like Cherry Studio and Chatbox. See [Chat Interfaces](/documentation/userdocs/ai/llm-managed/chat-interfaces).

If you want to **call the API** from Python, curl, or any OpenAI-compatible tool, see [API Access](/documentation/userdocs/ai/llm-managed/api-access). That page also covers cache isolation (`cache_salt`), which API users sharing a tenant should enable.

If you're setting up a **coding CLI** like Claude Code, OpenCode, Crush, Kimi CLI, pi, or Copilot CLI, jump to [Client Configurations](/documentation/userdocs/ai/llm-managed/client-configs) for ready-to-paste configs.

## Choose a model

The [feature matrix](/documentation/userdocs/ai/llm-managed/models) compares every active model side-by-side — context window, multimodal kinds, tool calling, reasoning, and what each one is best at. A few quick recommendations:

- **Frontier reasoning, longest context, multimodal** — `qwen3`
- **Agentic coding** — `kimi`, `glm-4.7`, or `minimax-m2`
- **Multimodal with audio** (ASR, speech-to-text) — `gemma-small`
- **Reproducible research / general-purpose LTS** — `gpt-oss`
- **Embeddings for vector search** — `qwen3-embedding`

Each model card links to its HuggingFace page and lists strengths, weaknesses, and recommended uses.

## Before you scale up

The NRP applies a [Fair Use Policy](/documentation/userdocs/ai/llm-managed/fair-use) with per-model concurrency limits — please review it before sending high-volume traffic. SDSC and Internet2 affiliates get higher limits.

For live capacity and health, see the **[LLM Status](/llm-status)** page (Prometheus / vLLM metrics, one card per Kubernetes container).

## Deploying your own model

If the managed catalog doesn't fit your need, the NRP supports running your own LLM via vLLM or SGLang — see [Managing AI Models](/documentation/admindocs/ai/managing_models/).
