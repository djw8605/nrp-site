# Managing Namespaces

This document outlines the steps to manage Kubernetes namespaces within the platform.

## Create a Namesapce

Use the website, and fill out the details in the form.

:::caution
Do **not** use `kubectl create namespace`.
:::

## Delete a Namespace

1. Move any Authentik group children.  
2. Remove the Authentik group.  
3. Delete the namespace.
4. Remove any exceptions in the portal configuration and any Gatekeeper exceptions.
