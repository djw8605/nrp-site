title: Cluster User Management
description: Managing users in the cluster.
---


This document outlines the steps to manage user roles and permissions within the platform.

## Add a User to a Namespace

On the [Namespaces](/namespaces) page, select the namespace and use its **Members** tab. Namespace membership
corresponds to an Authentik group for the namespace.

## Promote a User to Admin

On the [User info](/userinfo) page, look the user up and select **Make NRP admin…**. Adminship is one
platform-wide role: it corresponds to the Authentik group "namespace admins", and lets the user manage every
namespace they belong to, and the namespaces under those.

## Demote an Admin to User

On the [User info](/userinfo) page, look the user up and select **Remove NRP admin…**. This removes them from
the Authentik group "namespace admins".
