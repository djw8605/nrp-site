#### Upgrading Prometheus and Grafana

Grafana is included as a part of multiple definitions generated by [monitoring pipeline](https://gitlab.nrp-nautilus.io/prp/monitoring). Grafana itself and dashboards are automatically deployed to the cluster, while other components need to be manually deployed from CI/CD job artifacts.

Currently the grafana datasources is not generated properly and has to be excluded from the upgrades.

Also the 2 rules definitions have the prometheus version hard-coded.

CRD upgrade might need `--force-conflicts=true --server-side=true` added to the kubectl apply command.
