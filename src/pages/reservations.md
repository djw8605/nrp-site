## Node taints

You can request reserving certain nodes for a period of time using [the form](https://airtable.com/appfVVZLgTvG04pKe/pagfrjdaRo6UtSoux/form).

To use the reservation, set the [appropriate taint](/documentation/userdocs/running/special/) on your pods.
